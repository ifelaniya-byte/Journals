# Second-pass polish — what changed and why

The catalog was reviewed against a strong comparable paperback system for the things a buyer actually sees first: editorial cover hierarchy, meaningful interior previews, SKU distinction, listing completeness, metadata discipline, and automated QC.

## Improvements applied
- Replaced one repeated concentric-circle cover treatment with **18 product-specific line motifs**—square breath, petals, calendar sun, soft wave, moon, movement figure, abstract signal, card stack, breath waves, quilt, radial integration mark, tree, mandala, overlapping circles, desk grid, and calm-money rings.
- Rebuilt all 18 KDP cover wraps and cover images using an embedded serif/sans typography system, visible collection imprint, a product-specific value badge, and more useful back-cover hierarchy.
- Rebuilt `listing_06_callout.jpg` as a polished, verifiable format/price card and `listing_07_series.jpg` as a true collection collage using real product covers.
- Preserved the quiet, white-space-forward interiors, but kept each product’s unique interaction visible in four interior listing images.
- Kept cover titles short and elegant while retaining searchable Amazon titles in `metadata.txt`.

## Integrity rules retained
- KDP products show only the materials they actually contain.
- No outcome, treatment, dosing, financial, therapeutic, or restricted-brand claims were added.
- Cover-wrap math, barcode clear area, page count, images, metadata, and checklists remain validator-controlled.

## What not to “polish away”
The simplicity is intentional. These are low-content self-reflection products, not dense self-help manuals. White space, optional prompts, and low-pressure navigation are part of the value proposition.
