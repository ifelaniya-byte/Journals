## Price-change protocol

No price changes through a template, direct `metadata.txt` edit, rebuild default, or marketplace setting are valid unless this table and the relevant Gate Log record are updated first. Once all six Wave 1 values are confirmed, the controlled repair is: update `build_catalog.py` → rebuild → run `verify_pricing.py` and `validate_catalog.py` → compare source/baseline/current metadata → inspect price callouts and upload checklist → commit/tag. A deliberate future test price must state SKU, hypothesis, period, traffic source, expected contribution impact, owner, and rollback condition in the Scorecard Gate Log before deployment.
