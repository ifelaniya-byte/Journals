# Embedded font inventory and redistribution status

This repository contains only the following embedded fonts:

| File family | Use | Source / redistribution status |
|---|---|---|
| DejaVu Serif | Cover-wrap and listing-image editorial typography | DejaVu Fonts project; permissive Bitstream Vera–derived license with public-domain additions. |
| DejaVu Sans | Cover-wrap and listing-image functional typography | DejaVu Fonts project; permissive Bitstream Vera–derived license with public-domain additions. |

No commercial, client-supplied, or restricted font file is embedded in this repository. Do not add a font file unless its license explicitly permits repository redistribution and production use. Record its source, license, and intended use here before committing it.
