# 18 print-ready KDP journal interiors

Grayscale, undated, no-bleed interiors generated for the 18 briefs (9 GLP-1 trackers + 9 wellness). All medical-adjacent copy is **tracking / management** language with a disclaimer on page 2. No dosing protocols, no QR codes, no manufacturer branding.

## Upload settings (every title unless noted)

| Setting | Value |
|---|---|
| Interior type | Black & white with bleed **OFF** |
| Paper | White (cleaner grids; cream is OK) |
| Fonts | Embedded (Cormorant Garamond + Source Sans 3) |
| Margins | ~0.50″ outer, ~0.72″ gutter, ~0.46″ top, ~0.50″ bottom |
| Dates | Undated — `Date ______` + weekday pills |

**Trim exceptions**

- **07 Titration notebook** — **5 × 8 in** (KDP’s pocket trim; 4 × 6 is not a KDP size)
- **09 Injection sticker calendar** — **8.5 × 11 in**, white paper (stickers grip better than cream)

## Compliance notes already baked in

- Page 2 disclaimer: not medical advice, not affiliated with any manufacturer.
- Dose fields are labeled **as prescribed / as Rx / copy from the bottle**.
- Postpartum interior tracks *assigned PT homework* — it does not prescribe exercises or ship QR videos.
- Titration notebook records dates; it does not tell the reader when to escalate.
- Fasting / sobriety / migraine books include stop-rules (detox danger, worst-headache, etc.).

## Cover pairing

These interiors expect a **discreet, giftable** cover (soft type, no organ diagrams, no injectable-pen hero shot). 6×9 covers need KDP’s current cover calculator for the exact spine (spine width depends on page count + paper). 5×8 and 8.5×11 need their own cover files.
